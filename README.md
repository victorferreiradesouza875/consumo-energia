## 📌 Sobre o projeto

Este projeto tem como objetivo calcular o consumo de energia elétrica de um
equipamento com base na potência, no tempo de uso e no custo do kWh.

## 🐍 Tecnologia utilizada

- **Linguagem:** Python 3

## 🧮 Fórmula utilizada

Consumo (kWh) = (Potência (W) × Tempo de uso (h)) / 1000

Custo (R$) = Consumo (kWh) × Tarifa (R$/kWh)
